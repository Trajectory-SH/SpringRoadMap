	[1]preHandle()의 로그인 체크 조건 오류

	•	문제: 세션에서 **"u"**라는 이름으로 가져오고 있음
	•   조건에서는 "user"  키로 저장되어있다고 하는데 키의 이름이 다르다.

	즉, 항상 null이므로 true가 리턴되어 인터셉터가 로그인되지 않은 상태도 통과시키고 있음


	[2] 로그인 안되어있을때 main 페이지로 redirect 해야함

	현재 preHandle()에서 단순히 true/false만 반환하고 있으며,
    	•	로그인 실패 시 리다이렉트 처리 없음
    	•	즉, 로그인 안 된 경우에도 단순히 false만 리턴해서 “요청만 차단되고 사용자 경험 없음” 상태


문제 원인:
	•	세션 키 이름 불일치 ("u" vs "user")
	•	로그인 실패 시 리다이렉트 처리 없음
	•	일부 보호 URL 누락

조치 사항:
	•	세션 키 "user"로 수정
	•	로그인 실패 시 메인 페이지로 response.sendRedirect()
	•	addPathPatterns()에 필요한 URL 모두 포함
